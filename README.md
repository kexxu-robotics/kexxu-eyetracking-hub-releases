## About

Kexxu Eye Tracking Hub is the desktop companion for the **Kexxu Eye**, a fully portable, standalone wearable eye tracker developed in Amsterdam. The glasses record the eye with one camera and the scene with another, drawing a gaze crosshair on the scene video so you can see exactly where someone is looking.

This repository hosts the **official release builds** of the desktop app. The source code is not published here.

## Features

- 🔌 **Device connection** — find and connect to your Kexxu Eye glasses
- 🎯 **Calibration** — calibrate the eye tracker before each session
- ⏺️ **Recording** — start and stop gaze recordings
- 👀 **Live view** — watch the scene camera with the gaze overlay in real time
- ☁️ **Cloud sync** — upload recordings to the Kexxu Cloud for analysis on [editor.kexxu.com](https://editor.kexxu.com) (heat maps, gaze plots, areas of interest and more)

## Download & Installation

Go to the [**Releases**](../../releases/latest) page and download the file for your operating system.

| OS | File | How to install |
|----|------|----------------|
| 🪟 Windows | `.exe` | Run the installer and follow the steps |
| 🍎 macOS | `.dmg` | Open the file and drag the app to **Applications** |
| 🐧 Linux | `.AppImage` / `.deb` | `chmod +x` the AppImage and run it, or install the `.deb` with `sudo apt install ./file.deb` |

> **Note:** On first launch, Windows SmartScreen or macOS Gatekeeper may warn you about the app. On Windows click **More info → Run anyway**; on macOS right-click the app and choose **Open**.
